# 全辩计时器

Browser timer for debate competitions. Use Node.js 22 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:3210/. For a production run, use `npm run build` followed by `npm start`.

Before moving from the old browser origin, export your match as a ZIP. Keep copies of original backgrounds and fonts in case an older export omitted them. The sample match format is in `saizhi.json`.
